# Betty 0.6 사용성 QA (2026-10-23)

실제 팀 데이터(업무 256개, 프로젝트 9개, 팀원 14명)로 모든 화면을 확인했다. 아무것도 바꾸지 않고 보기만 했다.

## 큰 문제

1. **프로젝트가 섞여 있다.** 팀 전체·담당자 없음·보드가 업무 256개를 상태별로만 나눠서, 어느 프로젝트 일인지 한눈에 안 보인다. 보드의 할 일 열에만 182개가 있다.
2. **프로젝트 색이 전부 같다.** 모든 프로젝트가 기본 보라색(#7564d9)이라 점과 태그로 구분이 안 된다(프로젝트 미정만 회색).
3. **업무 삭제가 없다.** "안녕"(BT-317)처럼 잘못 생긴 업무를 지울 방법이 없다.
4. **하위 업무가 없다.** 진행 상황(끝난 부분·남은 부분)은 자동 정리만 채우고 사람은 고칠 수 없다.

## 화면별

| 화면 | 문제 |
|---|---|
| 사이드바 | 보기 7개 + 프로젝트 9개 + 팀원 14명이라 길다. 업무 없는 프로젝트(게임 프로젝트 1, 우마소 0)도 같은 무게로 나온다. |
| 목록 카드 | "진행 중" 묶음 안 모든 카드에 '진행 중' 태그가 또 붙는다. 모든 행에 ❚❚ 버튼이 있어 시끄럽다. 담당 없음이 '?' 동그라미로 나온다. 프로젝트 이름이 흐린 회색이라 잘 안 보인다. |
| 확인해 주세요 (34개) | 설명이 길고 "추가 확인" 기록이 계속 쌓여 카드 하나가 화면을 다 차지한다. 같은 업무에 대한 수정 제안이 두 번 나온다(대결 콘텐츠 개선 방향). 수정 제안은 무엇이 바뀌는지 보이지 않는다. 프로젝트별로 묶여 있지 않다. |
| 개발 현황 | 같은 업무(BT-248)에 PR 5개가 같은 긴 설명으로 5번 반복된다. |
| 보드 | 프로젝트를 고르지 않으면 182개 카드가 한 열에 쌓인다. 상세를 열면 완료 열이 가려진다. |
| 팀 현황 | 담당자 없음이 189개로 표 대부분을 차지한다. 미배정 업무를 정리할 흐름이 없다. |
| 업무 상세 | 진행 상황이 읽기 전용이다. 자동 정리 기록이 "불러오는 중…"에 오래 머문다(확인 필요). 삭제 버튼이 없다. |

## 결정한 방향

- 하위 업무: **체크리스트**. 지금의 끝난 부분·남은 부분을 그대로 체크리스트로 쓰고, 사람도 추가·체크·수정·삭제한다.
- 삭제: **휴지통**. 목록에서 사라지고 되살릴 수 있다. 베티가 같은 대화로 다시 만들지 않도록 기억해 둔다.
