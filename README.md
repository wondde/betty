# Betty

BerryTicket을 위한 macOS 앱입니다. 나에게 배정된 업무를 급한 순서로 보여 주고, 어디서든 단축키로 업무를 추가할 수 있습니다.

- **3단 화면**: 왼쪽 사이드바, 가운데 목록, 오른쪽 상세. 사이드바는 네 곳만 있습니다.
  - **내 할 일**: 나에게 맡겨진 일, 급한 순서.
  - **팀 할 일**: 팀 전체 업무를 프로젝트별로. 위쪽에서 프로젝트를 고르거나 "아무도 안 맡은 일"만 보고, 목록·보드(⌘B)를 바꿉니다.
  - **베티가 찾은 일**: 베티가 디스코드 대화에서 찾은 할 일 후보. 맞으면 넣고 아니면 넘깁니다.
  - **캘린더**: 팀 회의.
  - 그 아래 **프로젝트**와 **팀**(개발 · 디자인 · 마케팅, 펼치면 사람별). 팀원 영역은 설정에서 정합니다.
- **정리하기**: 팀 할 일 위쪽 버튼. 아무도 안 맡았거나 일주일 넘게 그대로인 일을 오래된 순으로 하나씩 보여 주고, 1 내가 할게 · 2 담당 지정 · 3 이미 끝났어요 · 4 필요 없어요(휴지통) · → 건너뛰기로 바로 정리합니다.
- **지금 하고 있는 일**: 팀 할 일과 팀 영역 화면 맨 위에 사람마다 진행 중인 일을 한 줄로 보여 줍니다. 담당 없이 진행 중인 일 수도 알려 줍니다.
- **설정 (⌘,)**: 일반 · 팀원·프로젝트(영역, 색, 채널) · 자동화(스위치와 베티가 한 일 기록) · GitHub 저장소 · 휴지통.
- **업무 편집**: 상세 창에서 제목, 설명, 상태, 담당자, 마감, 우선순위, 프로젝트, 종류를 바로 고치고 "내가 할게"로 가져옵니다. 바뀐 내용은 내 이름으로 기록됩니다.
- **업무 상세**: 체크리스트, 연결된 PR·이슈와 진행 단계, 피그마 화면, 디스코드 원문, 이 업무에 베티가 한 일을 함께 보여 줍니다. 베티가 같은 업무 같다고 본 PR·이슈는 연결 아래에 "같은 업무?"로 작게 나오고 ✓/✕로 답합니다(목록 카드에는 "PR 확인" 표시).
- **체크리스트(하위 업무)**: 항목을 추가·체크·지우고, 직접 쓴 항목은 두 번 눌러 고칩니다. 자동 정리가 확인한 끝난 부분·남은 부분도 같은 체크리스트에 근거 링크와 함께 들어옵니다. 목록 카드에 ☑ 2/5처럼 진행이 보입니다.
- **휴지통**: 상세의 "휴지통으로 옮기기"나 ⌘⌫로 지웁니다. 지운 업무는 모든 목록에서 빠지고, 설정 → 휴지통에서 되살릴 수 있습니다. 베티는 지운 업무를 같은 대화로 다시 만들지 않습니다.
- **프로젝트별 보기**: 프로젝트마다 색이 다르고(설정에서 바꿀 수 있음), 팀 할 일과 팀원 목록은 프로젝트별로 접히는 묶음과 위쪽 프로젝트 칩으로 나뉩니다. 보드는 프로젝트 하나씩 봅니다.
- **대화로 할 일 만들기 (⇧⌘N)**: 카톡, 회의 메모 등 다른 곳의 대화를 붙여 넣으면 베티가 할 일을 찾아 정리합니다. 찾은 일은 "베티가 찾은 일"에 올라옵니다. 그 화면에도 버튼이 있습니다.
- **보기 단축키**: ⌘1 내 할 일 · ⌘2 팀 할 일 · ⌘3 베티가 찾은 일 · ⌘4 캘린더 · ⌘B 목록/보드
- **검색 (⌘F)**: BT 번호, 제목, 설명, 담당자, 프로젝트 이름으로 찾습니다. ↑↓로 업무를 고르고 Esc로 닫습니다.
- **일반 맥 앱**: Dock 아이콘과 앱 메뉴(Betty · 파일 · 편집 · 보기 · 윈도우 · 도움말)가 있습니다. 창을 닫아도 Betty는 계속 실행되면서 알림을 받고, Dock 아이콘을 누르면 창이 다시 열립니다. 종료는 ⌘Q입니다.
- **처음 로그인하면 사용법 안내**가 6단계로 나오고, 마지막 단계에서 알림과 로그인 시 자동 실행을 켤 수 있습니다. 도움말 → "Betty 사용법 다시 보기"로 다시 볼 수 있습니다.
- **업무 카드**: 동그라미를 누르면 완료됩니다(1.6초 안에 다시 누르면 취소). ▶/❚❚로 시작하거나 멈추고, 카드를 누르면 설명과 막힘, 원문, 보드 링크가 나옵니다.
- **정렬**: 마감 임박 → 새로 들어온 일 → 진행 중 → 막힘 → 할 일 순서로 묶어서 보여 줍니다.
- **할 일 추가**: 창 아래 입력창 또는 ⌘N. `@민수 배너 문구 정리 #나루 금요일까지`처럼 쓰면 담당자, 프로젝트, 마감일이 한 번에 정해지고, 이름과 프로젝트는 자동완성됩니다.
- **어디서든**: ⌥⌘N 빠른 추가(Spotlight처럼 화면 가운데에 뜸), ⌥⌘B Betty 창 열기.
- **메뉴바 아이콘**: 보조 수단입니다. 누르면 Betty 창이 열리고, 옆 숫자는 남은 업무 수입니다(노치에 가려질 수 있어요).
- **로그인**: Discord 로그인 후 기기 토큰을 **키체인**에 저장합니다. 로그아웃하면 서버에서도 이 기기가 해제됩니다.

## 구조

```
main.go                 앱 메뉴, 메인 창, 빠른 추가 패널, 메뉴바 아이콘, 전역 단축키, 단일 실행
betty.go                프런트엔드가 부르는 유일한 서비스: 동기화(15초), 알림, 로그인, 업무 변경
internal/berry          BerryTicket 위젯 API 클라이언트 (/api/widget/*, /api/devices/*)
internal/signin         Discord 로그인: 시스템 브라우저 + 127.0.0.1 루프백 콜백 (RFC 8252) + PKCE식 검증
internal/vault          키체인에 기기 토큰 보관
internal/prefs          ~/Library/Application Support/Betty/prefs.json: 확인한 업무, 오프라인 스냅샷
frontend/src            Svelte 5: TaskWindow(목록), Onboarding(첫 안내), Sheet(설정·단축키·정보), QuickAdd, Composer(@ # 날짜 입력)
tools/appicon/betty.swift  앱 아이콘·Icon Composer 레이어·메뉴바 아이콘·화면용 이미지를 한 번에 그리는 스크립트
```

Go 서비스가 바뀌면 `betty:view` 이벤트로 모든 창에 같은 상태가 전달됩니다. 네트워크와 키체인 작업은 전부 Go 쪽에서 하고, 화면은 그리기만 합니다.

## 개발

필요한 도구: Go 1.26+, Node 20+, Xcode Command Line Tools, Wails v3 CLI(`go install github.com/wailsapp/wails/v3/cmd/wails3@latest`)

```sh
wails3 dev                      # 개발 모드 (핫 리로드)
wails3 task darwin:package      # bin/betty.app
go test ./internal/...          # 로그인 흐름, API 클라이언트 테스트
BETTY_SERVER=http://127.0.0.1:8000 open bin/betty.app   # 로컬 BerryTicket 서버에 연결
```

서버 측 요구사항: BerryTicket에 Discord 로그인, 기기 토큰, 위젯 API, 루프백 리디렉션(`redirect=http://127.0.0.1:<port>/callback`), 기기 토큰의 보드 API 접근(0.3부터)이 배포되어 있어야 합니다.

`BETTY_SERVER`를 지정하면 키체인 항목, 설정 폴더(`Betty-dev`), 단일 실행 ID가 모두 개발용으로 분리되어 실제 로그인에 영향을 주지 않습니다.
